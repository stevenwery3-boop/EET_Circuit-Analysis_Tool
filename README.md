# EET_Circuit-Analysis_Tool & Dashboard
This project is a desktop application built with python and Tkinter to support basic Electrical Engineering Technology(EET) concepts such as ohm's law, power calculation, AC signals and resistor color coding. 

# Features 
- Ohm's law and power calculator:
  . calculates voltage, current, resistance and power
  . user inputs any two values then the app computes the others
  . includes error handling ( invalidating inputs, division by zero)
- AC waveform plotter:
  . generates sinusoidal signals using frequency and amplitude
  . displays the waveform using graph
  . helps visualize AC behavior over time
- Resistor color code calculator:
  . converts 4-band resistor colors into resistance values
  . displays results in Ω, kΩ or MΩ
  . includes tolerance values 

  # Technology used
  - Pyhton 3
  - Tkinter (GUI)
  - Matplotlib
